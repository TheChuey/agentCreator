# TASK: Extract GenV1 Agent Engine and Build a Headless App Connected to Project Manager

## OBJECTIVE
Extract GenV1's core agent engine (`engine/`) and tool definitions (`tools/`), stripping out `server/` and `dashboard/` [13, 14]. Build a standalone `headless_app/` package containing a dynamic `interface_runner.py` and a `bridge/` module that connects agent executions and chat endpoints directly to the Project Manager application (`EditorClient` / `EditorInterface`) [2, 11].

## KEY IMPLEMENTATION STEPS

### 1\. Refactor Engine &amp; Tools

* **Engine Core (** **engine/core/** **)**: Retain the 3-step `think()` \-&gt; `act()` \-&gt; `observe()` execution loop in `agent.py`[9]. Ensure `llm.py` connects to local Ollama endpoints[9][10].
* **Remove Web Dependencies**: Eliminate all imports pointing to `server/` or `dashboard/`[11].
* **Session Safety**: Maintain `FileSession` in `tools/state.py` and enforce tool-loop safety limits (`MAX_TOOL_ROUNDS = 6`, `REPEAT_LIMIT = 3`)[11][9].

### 2\. Implement `bridge/client.py`

* Create `ProjectManagerBridge` using Project Manager's sync `EditorClient` and async `AsyncEditorClient`[2][5].
* Expose high-level wrappers for `open()`, `save()`, `tree()`, and `/api/chat`[2].

### 3\. Bind Agent Tools to Project Manager

* In `tools/project_tools.py`, replace direct Python OS filesystem calls with `bridge.read_file()`, `bridge.write_file()`, and `bridge.get_tree()`[2][6].
* Ensure all file modifications flow through `parameters/filesystem.py` via Project Manager's REST layer, triggering real-time WebSocket events (`/api/ws`)[13].

### 4\. Implement `interface_runner.py`

* Expose `AgentInterface` with:
  * `run_single_agent(json_path, md_path, user_input)`: Dynamically builds and runs a single agent.
  * `run_pipeline(agent_configs, user_input)`: Executes a multi-agent chain (e.g., Planner -&gt; Engineer -&gt; Builder), passing accumulated context downstream[15].

### 5\. Connect Project Manager `/api/chat` Route

* In Project Manager's `interface/routers/chat.py`, replace the chat log stub with calls to `AgentInterface.run_single_agent()`, allowing the Monaco Editor UI and web chat popup to interact directly with the transplanted engine[7][8].
